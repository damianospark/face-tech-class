# fi-cv-demo
고전적 컴퓨터 비전(Classic CV) 기법으로 안면 특징을 단계적으로 추출·비교하는 교육용 데모입니다. 얼굴 검출 → 정렬/정규화 → 파트(눈/코/입) 분리 → LBP 기반 임베딩 → 코사인 유사도 비교 과정을 통해, 동일인 여부 판단에 필요한 핵심 개념을 이해하도록 돕습니다.

## 프로젝트 구조
```
fi-cv-demo/
├─ demo.py                  # 메인 데모 파이프라인(이미지 한 쌍 처리)
├─ generate_report.py       # 임베딩 시각화/리포트 생성(3D PCA, HTML)
├─ requirements.txt         # 의존성 목록
├─ README.md                # 사용법 및 산출물 설명
├─ output-enroll/           # 등록 이미지(enroll) 산출물 폴더
├─ output-chk/              # 인증 이미지(probe) 산출물 폴더
└─ report/                  # 리포트 산출물 폴더(report_3d.png, report.html)
```

## 요구사항 설치
```bash
python3 -m pip install -r requirements.txt
```

# 테스트 방법
1) 입력 이미지 준비
- 이 디렉토리(`fi-cv-demo/`) 루트에 다음 파일을 둡니다:
  - `face.png` 또는 `face.jpg` (등록 이미지)
  - `face-chk.png` 또는 `face-chk.jpg` (인증 이미지)
- 권장 조건:
  - 얼굴 전체가 뚜렷이 보이는 정면에 가까운 사진
  - 적절한 조명, 과도한 그림자·가림·왜곡·저해상도 지양

2) 실행
```bash
python3 demo.py
```
- 루트에 위 파일들이 없으면, 자동으로 상위 폴더의 `fi-classic/face.jpg`, `fi-classic/face-chk.jpg`를 폴백 입력으로 사용합니다.

## 출력 및 결과 파일 의미
실행 후, 이 디렉토리에 다음 폴더/파일이 생성됩니다.

- 출력 폴더
  - `output-enroll/` 등록 이미지에 대한 중간 산출물
  - `output-chk/` 인증 이미지에 대한 중간 산출물

- 단계별 산출물(주요 파일)
  - `01_detection.jpg`
    - 얼굴 탐지 결과 시각화(녹색 박스). 탐지가 실패하면 원본의 중심부를 크롭해 저장.
    - 안면인식에서 얼굴 영역을 정확히 추출하는 단계. 잘못 검출되면 이후 단계 품질 저하.
  - `02_aligned.jpg`
    - 단순 정렬 결과(현재 버전은 각도 0으로 저장). 정렬은 얼굴 포즈/회전을 보정해 특징 비교를 공정하게 하기 위함.
  - `03_preprocessed.jpg`
    - `160x160` 크기로 정규화 + 그레이스케일 + 히스토그램 평활화 적용된 이미지.
    - 조명/대비 조건을 맞춰 특징의 안정성을 높이는 전처리.
  - `04_aligned_parts_overlay.jpg`
    - 눈/코/입 등 파트 위치를 사각형으로 덧그린 오버레이.
    - 파트 기반 특징 추출이 어느 위치에서 됐는지 확인 가능.
  - `05.01_left_eye.jpg`, `05.02_right_eye.jpg`, `05.03_nose.jpg`, `05.04_mouth.jpg`
    - 파트별 크롭 이미지. 파트 단위로 지역 특징을 비교해 전체 견고성을 높임.
  - `05.10_embedding_<part>_lbp.jpg`
    - 각 파트에서 계산된 간단한 LBP(Local Binary Patterns) 맵 시각화.
    - LBP는 질감/패턴 정보를 담는 고전적 특징으로, 조명변화에 비교적 강함.
  - `05.20_enroll_embedding.npy` / `05.20_probe_embedding.npy`
    - 등록/인증 임베딩 벡터(numpy 배열). 파트별 LBP 히스토그램을 이어붙여 정규화한 벡터.
    - 안면인식에서 임베딩은 얼굴을 수치적 벡터 공간에 표현한 것으로, 거리/유사도로 동일인 여부를 판단하는 핵심 데이터.
  - `05.20_enroll_embedding.txt` / `05.20_probe_embedding.txt`
    - 같은 내용을 텍스트로 저장해 사람이 확인하기 쉽게 한 버전.
  - `06_compare.jpg`
    - 등록/인증 전처리 결과 이미지를 좌우로 붙이고, 하단에 주요 유사도(overall 및 파트별)를 표시한 비교 캔버스.
    - 사람이 결과를 빠르게 검토할 수 있는 시각 요약.
  - `07_result.txt`
    - 최종 유사도 요약 텍스트. 예시:
      - `overall_cosine:0.873421`
      - `left_eye_cosine:0.812345`
      - `right_eye_cosine:0.845678`
      - `nose_cosine:0.790123`
      - `mouth_cosine:0.801234`
    - 안면인식 관점:
      - overall_cosine은 전체 임베딩 간 코사인 유사도(1에 가까울수록 유사).
      - 파트별 코사인 값은 특정 파트(눈/코/입) 일치도를 개별적으로 보여, 부분적 실패/가림 등을 진단하는데 유용.

- 리포트 생성 스크립트
  - `generate_report.py`
    - `report/report_3d.png`와 `report/report.html`을 생성.
    - `05.20_*.npy` 임베딩 두 개를 PCA(3D)로 투영해 화살표 벡터로 시각화하고, 원공간의 코사인/유클리드 거리도 함께 표기.
    - 코사인 유사도는 방향 일치도를, 유클리드 거리는 절대 차이를 반영.
  - 실행:
    ```bash
    python3 generate_report.py
    ```
    - 출력: `report/report.html`을 브라우저로 열어 시각적으로 검토.

## 기술적 배경 요약
- 이 데모는 “고전적 CV” 흐름을 교육용으로 단순화한 것입니다.
  - 얼굴 검출 → 정렬/정규화 → 파트 추출 → LBP 기반 임베딩 → 코사인 유사도 비교
- 임베딩은 얼굴의 정량 표현입니다. 동일인 비교는 두 임베딩 간의 유사도(코사인)를 높게, 다른 사람은 낮게 만드는 것이 목표입니다.
- 파트별 비교는 특정 부위의 불일치, 가림, 표정 변화에 대한 민감도를 확인하게 해 줍니다.

## 가이드라인 (판단 기준)
이 데모의 임베딩은 정규화(norm=1)를 적용하므로, 두 가지 주요 지표의 범위와 해석은 다음과 같습니다.

- Cosine Similarity: [0, 1]
  - 1.0에 가까울수록 방향(특징)이 매우 유사함을 의미
- Euclidean Distance: [0, √2] ≈ [0, 1.414]
  - 0에 가까울수록 두 벡터가 가깝고 유사함을 의미
  - 두 지표의 관계: d = sqrt(2 - 2·cos)

권장 임계값 예시(일반 가이드, 환경/데이터에 따라 조정 필요):

- Cosine Similarity 기준
  - ≥ 0.90: 동일 가능성 매우 높음 (자동 승인 후보)
  - 0.85 ~ 0.90: 동일 가능성 높음 (휴리스틱/수작업 검토 권장)
  - 0.75 ~ 0.85: 애매권 (추가 샘플/조건 점검 필요)
  - < 0.75: 비동일 가능성 높음

- Euclidean Distance 기준(위 코사인 임계에 상응, 근사치)
  - ≤ 0.45: 매우 가깝다 (cos ≳ 0.90)
  - 0.45 ~ 0.55: 가깝다 (cos ≈ 0.85 ~ 0.90)
  - 0.55 ~ 0.70: 애매권 (cos ≈ 0.75 ~ 0.85)
  - > 0.70: 멀다 (cos < 0.75)

주의 사항 및 팁:
- 위 임계값은 교육용 데모 기준의 “초기 가이드”입니다. 실제 서비스에서는 본인의 데이터셋으로 ROC/EER 분석을 통해 최적 임계값을 재보정하세요.
- 입력 조건(정면, 조명, 해상도, 가림/표정 변화)에 따라 값이 크게 달라질 수 있습니다. 가능한 한 얼굴 전체가 보이고 선명한 이미지를 사용하세요.
- 파트별 코사인 값이 전체 판단과 불일치할 경우, 특정 부위(예: 입의 가림, 눈 반사 등) 문제를 의심하고 원인을 분리하여 확인하십시오.
